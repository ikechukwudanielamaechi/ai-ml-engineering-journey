## What's in this repo

### `daily-practice/`
Daily Python exercises, organized by week in months, tied to whatever CS50P concept I'm on at the time (currently: File I/O, Week 6). Each exercise is paired with its own unit tests — I don't consider an exercise done until it's tested.

### `project-bridge/`
Research notes and (eventually) experiments for my long-term project: a Nigerian Sign Language recognition system, part of a larger vision for a Speech ↔ Text ↔ Sign Language communication tool.

### `notebooks/`
Reserved for NumPy/Pandas/Kaggle work, starting once I complete CS50P.

## Why this approach

Most of my early work has focused less on rushing into libraries and more on building the *reasoning* real ML engineers need first: dataset integrity, signer-independent evaluation, data leakage, reproducibility and honest experiment documentation.
 I'm applying that thinking daily — including deliberately testing my own code for bugs, not just writing code that "looks" right.
